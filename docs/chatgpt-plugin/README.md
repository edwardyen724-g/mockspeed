# ChatGPT plugin draft

What OpenAI's plugin upload (platform.openai.com/plugins) takes, as read from its docs on 2026-09-30.
The format was new that week: zip these three files and let the uploader's validator say what it
wants changed. A demo recording URL (`review.demo_recording_url`) is required for MCP review and isn't
here yet. Reviewer credentials go in the dashboard, never in the zip. See ../directories-2026-09-30.md.
